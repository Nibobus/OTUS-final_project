# Система управления складом и запасами
## 📌 Описание информационной системы
Данная система представляет собой реляционную базу данных и набор аналитических инструментов для управления складскими операциями.
1. **Учет товаров и запасов:** Многоуровневая структура (Склад -> Зона -> Товар).
2. **Автоматическое пополнение:** Алгоритмы расчета точки заказа и генерации заказов поставщикам.
3. **Инвентаризация:** Фиксация расхождений, анализ точности учета.
4. **Аналитика и сегментация:** ABC-анализ товаров, RFM-сегментация клиентов, расчет оборачиваемости.

## 🛠 Технологии
* **СУБД:** PostgreSQL 15+
* **Язык:** SQL (PL/pgSQL для процедур)

## 📁 Структура проекта
* `docs/` - Документация, ER-диаграмма, описание оптимизаций.
* `sql/` - Скрипты DDL, DML, представлений, процедур и аналитики.
