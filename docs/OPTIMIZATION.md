# Методы оптимизации производительности

## 1. Партицирование таблиц (Table Partitioning)
Таблица `movements` (история движений товаров) разбита по диапазону дат (`RANGE` на `movement_date`).
**Влияние:** При аналитических запросах за конкретный месяц (например, ABC-анализ за квартал) PostgreSQL сканирует только нужную партицию, а не всю таблицу.

## 2. Создан индекс `idx_movements_product_date (product_id, movement_date)`.
**Влияние:** Позволяет эффективно выполнять запросы с фильтрацией по товару и сортировкой/фильтрацией по дате.

## 3. Материализованные представления
Сложные запросы (ABC-анализ, RFM) работают медленно, потому что считают много данных каждый раз.
**Влияние:** Дашборды открываются мгновенно, потому что данные уже посчитаны.

## 4. Генерируемые столбцы (Generated Columns)
В таблице `audit_items` поле `discrepancy` вычисляется автоматически (`GENERATED ALWAYS AS`).
**Влияние:** Исключает ошибки человеческого фактора при вводе и экономит время на вычисление расхождений в триггерах или на стороне приложения.
